# Seed and input inventory

Everything in `seeds/` is either an experiment configuration input or an
initialization record derived deterministically from one. None of it is a
measured output or a sample stream. Directed bit patterns used only by unit
tests stay in their source files.

| Role | Exact seed or recipe | Location |
|---|---|---|
| Quality configurations | PCG64 seed 20271013, four consecutive 32-byte key and 12-byte nonce draws | seeds/quality_config.json |
| Plane and local initial states | Fixed-width eleven-word mixing and coordinate adapters | seeds/postmix_cases.csv, seeds/local_initial_states.csv, seeds/plane_sources.csv |
| Uniform control | PCG64 seed 20271014, four consecutive full-shape uint8 calls | seeds/uniform_protocol.json |
| Directed restart cases | Two explicit eleven-word configurations, regenerated by directed_words | seeds/directed_restart_and_application.json, scripts/bootstrap_sources.py |
| Unequal-demand delivery | First directed restart configuration | seeds/directed_restart_and_application.json, experiments/slow_consumer/run.py |
| Complete-mesh applications | Key bytes 00..1f, little-endian nonce words 0, 1, 0 | seeds/directed_restart_and_application.json, src/sw/crypt_ppu.c and sobel_ppu.c |
| Extractor random vectors | NumPy default_rng seeds 11, 22 and 33, with 100000 uint64 input pairs per seed | src/tools/plane_ref.py:vectors |
| Baseline extractor self-check | NumPy default_rng seed 1, with 2000 pairs | src/tools/plane_ref.py:_check_fold_matches_baseline |
| Trivium reference self-check | NumPy default_rng default seed 1; direct key/IV patterns remain literal | src/baseline/reference_original/trivium_ref.py:selftest |
| Tent directed recurrence unit checks | Python random.Random(20271020) plus literal patterns | experiments/quality/nardo2023/{,strided/}run_unit.py |

The quality CSV records cover N=3, 4, 6 and 8, so the adapters can be inspected
at every mesh size in the workflow. The quality experiment itself uses N=6.

The restart and application seeds are deliberately different. The first
directed restart nonce words are 0x09000000, 0x4a000000 and 0. The
complete-mesh firmware writes 0, 1, 0. The delivery bench uses only the first
restart case. Subsystem equivalence and restart checks use both cases.

Trivium and ChaCha20 use their own initialization, IV mapping, warmup and
counter logic. Their workload configurations are the application or testbench
values above. Do not substitute the logistic postmix or the local LG/XS/TM
adapters into those comparator cores.
